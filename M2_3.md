# M2.3 — Training convergence pilot

Purpose: determine whether the M2.2 ablation behavior is caused by undertraining before changing the architecture.

**Do not resume the 1,000-row pilot when changing --limit or learning rate.** New output directories are required. Do not use SCUI/UCSI/UCUI to select epochs or hyperparameters. Validation currently groups by (city, image_name); it is still seen-city/source-task validation, not an unseen-task validation protocol.

Start with 5,000 source-training rows, 20 maximum epochs and patience 6. Qwen latent vectors cache between epochs. Same seeds, data and hyperparameters for both runs. The no-LLM baseline does not load Qwen.

```bash
for MODE in no-llm qwen3vl-latent; do
  python -u run_m2.py train \
    --train-csv /path/to/train.csv \
    --image-root /flash/project_462001391/xiyanxin/Urban_experience/output_files \
    --provider "$MODE" --model-id Qwen/Qwen3-VL-2B-Instruct \
    --limit 5000 --epochs 20 --patience 6 --batch-size 2 \
    --seed 42 --lr 0.0001 --val-fraction 0.1 \
    --cache-dir runs/qwen_cache --output "runs/m23_${MODE}"
done
```

Summarize convergence:

```bash
python scripts/report_convergence.py runs/m23_no-llm runs/m23_qwen3vl-latent
```

Optional plotting (only if matplotlib installed):

```bash
python scripts/plot_convergence.py runs/m23_no-llm runs/m23_qwen3vl-latent --output runs/m23_convergence.png
```

Only evaluate the held-out test protocols after choosing configurations from the training validation curves. For publication results, evaluate all three modes (including shuffled-latent), multiple seeds, and entire frozen test splits.

**Caveats:** `--limit` takes the first N CSV rows, not a random sample; source tasks may be imbalanced or absent in the prefix. The train/validation split is deterministic for a fixed CSV order/seed. Early stopping uses validation MSE, and resume restores best epoch from checkpoint metadata, but other hyperparameters besides those checked by the current loader should remain unchanged. Qwen and no-LLM have different parameter counts.

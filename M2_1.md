# M2.1 — separated training, validation, evaluation, resume and frozen MLLM cache

This is an engineering upgrade to M1.2. Actual MI250X execution is **not verified** as part of this commit.

Use your existing ROCm environment. Train with a **seen-city/source-indicator-only CSV**:

```bash
python run_m2.py train \
  --train-csv /path/to/train.csv \
  --image-root /flash/project_462001391/xiyanxin/Urban_experience/output_files \
  --provider qwen3vl-latent --model-id Qwen/Qwen3-VL-2B-Instruct \
  --limit 100 --epochs 3 --batch-size 2 \
  --output runs/m2_pilot --cache-dir runs/qwen_cache
```

The held-out validation set is created from the training CSV, **grouped by (city, image_name)**, avoiding the same tile in train and validation. This is not yet a city-grouped validation or a publication-ready cross-task validation protocol. **Never choose an epoch or hyperparameters on SCUI, UCSI, UCUI.**

Resume to a total of five epochs, including epochs already completed:

```bash
python run_m2.py train \
  --train-csv /path/to/train.csv \
  --image-root /flash/project_462001391/xiyanxin/Urban_experience/output_files \
  --provider qwen3vl-latent --model-id Qwen/Qwen3-VL-2B-Instruct \
  --limit 100 --epochs 5 --batch-size 2 \
  --resume runs/m2_pilot/last.pt \
  --output runs/m2_pilot --cache-dir runs/qwen_cache
```

Independent **final testing**, using one or more held-out protocol files:

```bash
python run_m2.py evaluate \
  --checkpoint runs/m2_pilot/best.pt \
  --train-csv /path/to/train.csv \
  --scui-csv /path/to/scui.csv --ucsi-csv /path/to/ucsi.csv --ucui-csv /path/to/ucui.csv \
  --image-root /flash/project_462001391/xiyanxin/Urban_experience/output_files \
  --cache-dir runs/qwen_cache --output runs/m2_eval
```

The frozen Qwen hidden-state cache key includes resolved image path, size/mtime, city, task description, source task ordering, and model ID. Cached vectors and checkpoints belong in `runs/`, not Git. The key does **not** hash image bytes or record a precise model revision; use a different cache path when weights change.

Smoke test without model weights or images:

```bash
python -m unittest discover -s tests -p 'test_m2.py' -v
```

The existing `train_m1.py` remains unchanged for backward compatibility.
